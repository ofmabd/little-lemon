# Little Lemon Restaurant

## Overview

Little Lemon is a React-based restaurant reservation web application developed as the Meta Front-End Developer Capstone project.

## Features

- Responsive design
- Table reservations
- Booking validation
- Dynamic reservation times
- Confirmation page
- Navigation
- Menu page
- About page
- Testimonials

## Technologies

- React
- React Router
- JavaScript
- HTML5
- CSS3

## Installation

git clone ...

npm install

npm start

## Run Tests

npm test

## Build

npm run build
